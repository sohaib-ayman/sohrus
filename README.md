# Sohrus · صوهروس

A lightweight, fast living notch for Windows with Arabic & English RTL support, designed to keep everyday utilities right at your fingertips.

**Created by:** Sohaib Ayman · **Built with:** Pure Rust · **Version:** 1.6.9

## Download & Install
1. Go to the **Releases** section or click **[Download Latest Release](../../releases/latest)**.
2. Download **`Sohrus-Setup-v1.6.9.exe`** and run it.
3. Follow the installer steps — no extra libraries or runtimes required.

> **Note about Windows SmartScreen:** Because Sohrus is an independent, free Windows app without a paid code-signing certificate, Windows may show a SmartScreen prompt on first launch. Click **More info** and then **Run anyway** to continue.

## Updating
To update to a newer version, download the latest installer from **Releases** and run it. Your settings and saved data will stay intact.
